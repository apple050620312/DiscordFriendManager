連線 Discord

Token 只保留在此分頁的記憶體，重新整理或關閉後即消失。好友快取與操作紀錄只寫入此瀏覽器的 IndexedDB，不會傳送到作者的伺服器。

如何取得 Discord user token
  1. 在瀏覽器開啟 Discord 網頁版並登入。
  2. 按 F12 開啟開發者工具，切換到「網路」或「Network」。
  3. 重新整理 Discord，搜尋 users/@me 請求。
  4. 在請求標頭找到 Authorization，只把值貼在上方欄位。

不要把 Token 傳給任何人或貼到公開場所。使用 user token 自動化可能違反 Discord 服務條款，請自行評估帳號風險。

清除本機快取？

清除後，目前畫面仍保留在記憶體中。下次啟動會重新向 Discord 取得資料。

隱私與安全

這是一個完全在瀏覽器執行的開放原始碼工具，沒有作者控制的後端伺服器。

  • Token只保留在目前分頁的記憶體，重新整理、登出或關閉分頁後即消失。
  • Discord 請求由你的瀏覽器直接傳送到 discord.com，不會經過作者的伺服器。
  • 本機資料好友快取與操作紀錄只寫入此瀏覽器的 IndexedDB，可隨時清除好友快取。
  • 網站連線GitHub Pages 仍會收到一般網站連線資料，例如 IP 位址與瀏覽器資訊。
