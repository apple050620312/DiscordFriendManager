Discord Friend Manager

整理、排序與檢視 Discord 好友關係，所有 API 請求都由你的瀏覽器直接送往 Discord。

尚未登入
帳號風險 使用 user token 自動化可能違反 Discord 服務條款，即使只讀或低頻操作仍有停權風險。本工具不是 Discord 官方產品。
開始使用

取得 Discord user token

Token 等同帳號登入憑證。只在自己的裝置操作，不要傳給任何人或貼到公開場所。

  1. 登入網頁版 Discord在一般瀏覽器開啟 Discord 並完成登入。
  2. 開啟開發者工具按 F12，切換到「網路」或「Network」分頁。
  3. 找到自己的請求重新整理 Discord，搜尋 users/@me。
  4. 複製 Authorization在請求標頭找到 Authorization，只將它的值貼入本工具。
資料流

隱私與安全

  • Token只保留在目前分頁記憶體，重新整理、登出或關閉分頁後即消失，也不會進入備份檔。
  • Discord 請求由瀏覽器直接傳送到 discord.com，不經過作者控制的伺服器。
  • 本機資料好友快取與操作紀錄只寫入此瀏覽器的 IndexedDB，可在資料管理頁匯出或清除。
  • 網站連線GitHub Pages 仍會收到一般網站連線資料，例如 IP 位址與瀏覽器資訊。

連線 Discord

Token 只保留在此分頁的記憶體，重新整理或關閉後即消失。好友快取與操作紀錄只寫入此瀏覽器的 IndexedDB，不會傳送到作者的伺服器。

清除本機快取？

這會刪除好友、關係時間與最後訊息掃描結果。操作紀錄不受影響。

清除操作紀錄？

這會永久刪除此瀏覽器中的移除好友與重新邀請歷程，不會變更 Discord 上的好友狀態。

匯入並取代本機資料？

已驗證備份檔。

移除好友

確定要將 從好友名單移除嗎？這會立即更新 Discord。

補齊最後訊息時間？

程式會逐位向 Discord 取得或建立 DM 頻道，不會讀取或傳送訊息。部分舊 DM 可能重新出現在 Discord 私訊清單。進度可暫停，重新啟動後可接續。

重新加好友

確定要向 送出好友邀請嗎？此操作只會送出邀請，對方仍需要接受。
